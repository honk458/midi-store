# 🎵 MIDI Store for Bruce Devices

> 🌍 **English** | **Tiếng Việt** (Scroll down for English / Cuộn xuống để xem bản tiếng Anh)

Kho chứa nhạc định dạng text đơn giản cho ứng dụng MIDI Player trên Bruce Firmware.

## 📝 Định dạng file nhạc (.txt)
Mỗi dòng là một nốt nhạc và thời gian ngân (ms), phân tách bằng dấu phẩy ",":

Ví dụ:

C4,200 
E4,200 
G4,400 
REST,100 

## ENGLISH

A lightweight store for text-based music files compatible with the **MIDI Player** app on **Bruce Firmware**.

### 📝 Music File Format (`.txt`)
Each line consists of a **Note Name** and **Duration (in milliseconds)**, separated by a comma ",":

Example:

C4,200 
E4,200 
G4,400 
REST,100
